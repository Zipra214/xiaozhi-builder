🔧 XiaoZhi ESP32 Builder

Cấu hình → Build firmware trên cloud → Nạp thẳng vào ESP32 qua USB

📋 Các bước
  1. Chọn board & cấu hình GPIO
  2. Build firmware trên GitHub Actions (cloud)
  3. Tải file .bin từ Artifacts
  4. Nạp firmware vào ESP32 qua USB
1️⃣ Board & Chip
📌 GPIO Mapping — chỉnh nếu dùng mạch tự thiết kế
⚡ Thực thi Sẵn sàng
💡 Cách dùng:
1. Bấm "Mở trang Build" → GitHub mở ra → bấm "Run workflow" màu xanh → đợi ~6 phút
2. Vào tab Artifacts ở cuối trang build → tải file .zip → giải nén lấy file .bin
3. Bấm "Chọn file .bin" → chọn file vừa tải
4. Cắm ESP32 vào máy → bấm "Nạp vào ESP32" (cần Chrome/Edge)
